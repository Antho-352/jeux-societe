## About Unfair - ABDW expansion

This Unfair expansion print-and-play page offers the ABDW rulebook, four themed card packs, Game Changers, and an A3 token sheet. It is an official personal-use-only resource.

The files are intended for trying the game or printing for personal use. This entry points to the official Unfair page only; it does not copy any publisher files or images.

## How to play in one minute

1. Start with the Unfair base game and the required expansion materials.
2. Choose the ABDW theme packs you want to include.
3. Build and play using the official expansion rules.
4. Use the official tokens or suitable substitutes where the rules require them.
