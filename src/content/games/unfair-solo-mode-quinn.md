## About Unfair - Solo mode "Quinn"

The official Unfair solo page provides Quinn, an automated opponent for solo play, through a rule leaflet and a flowchart card. Both files are marked v0.992 and updated 17 February 2022.

The files are intended for trying the game or printing for personal use. This entry points to the official Unfair page only; it does not copy any publisher files or images.

## How to play in one minute

1. Prepare Unfair and the Quinn solo materials.
2. Read the Quinn rule leaflet before beginning play.
3. Use the flowchart card when Quinn needs a decision.
4. Resolve the solo game with the official Quinn procedure.

Quinn rule leaflet and Quinn flowchart card, both A4/letter printable PDFs. The official page gives print guidance for its linked PDFs; this catalogue entry keeps those downloads with the publisher. Consult the official page for the current solo materials before printing.
